# SafeTag website

A small site that explains SafeTag and offers the latest Android test
build for download. It is a stopgap until the app is on the Play Store.

Plain HTML and CSS. Hosted on Vercel, which redeploys on every push to `main`.

## Pages

`index.html`, `pricing.html`, `about.html`, `contact.html`, `privacy.html`
and `terms.html` are generated by `build.py`, which wraps each page's text in
the shared header and footer. To change wording, edit `build.py`, then:

```
python build.py
git add -A
git commit -m "Update site text"
git push
```

| File | What it is |
|------|------------|
| `build.py` | All page text, and the header and footer |
| `styles.css` | The look of every page |
| `site.js` | Build details under the download buttons, and the contact form |
| `img/` | Photographs, from Pexels (free to use, no credit required) |
| `SafeTag.apk` | The build people download (arm64, for modern phones) |
| `version.json` | Version, build date and size shown under the download buttons |
| `vercel.json` | Makes the APK download as a file with the right type |
| `publish.ps1` | Puts a new build on the site |

## Contact form

Messages are emailed to the team's inbox by Web3Forms (free plan, 250 a
month). The access key in `site.js` is public by design. To change where
messages go, sign in at web3forms.com.

## Putting a new build up

```
cd C:\fyp\safetag
flutter build apk --release --split-per-abi

cd C:\fyp\safetag-site
powershell -ExecutionPolicy Bypass -File publish.ps1
```

The script copies the APK, updates `version.json`, commits and pushes. The
site shows the new build about a minute later.

## Notes

- The APK is the arm64 build, about 24 MB. Nearly every Android phone from
  the last several years uses it. A very old or unusual phone may refuse to
  install it; the universal build (`app-release.apk`, about 63 MB) works on
  those.
- Every published build stays in the git history, so the repository grows by
  the size of the APK each time.
